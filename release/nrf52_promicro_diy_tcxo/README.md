# nRF52 ProMicro DIY 多按钮功能固件

## 固件概述

本固件为nRF52 ProMicro DIY开发板实现了完整的多按钮功能，支持5个独立按钮的短按和长按操作，完全集成到Meshtastic固件系统中。

## 功能特性

### 多按钮支持
- **5个独立按钮**：P1.00、P1.01、P1.02、P1.06、P1.07
- **短按功能**：导航控制（上下左右、确认选择）
- **长按功能**：系统功能（关机、GPS切换、adhoc ping、DFU模式）
- **3秒长按时间**：防止误操作

### 技术特性
- ✅ 深度睡眠唤醒支持
- ✅ 中断驱动按钮检测
- ✅ 完全集成到InputBroker系统
- ✅ 与系统命令模块无缝集成
- ✅ 支持DFU模式进入

## 按钮映射表

| 按钮 | 引脚 | 短按功能 | 长按功能 (3秒) | 双击功能 |
|------|------|----------|----------------|----------|
| P1.00 | P1.00 | 确认选择 | 关机 | 无 |
| P1.01 | P1.01 | 向上导航 | 切换GPS模式 | 无 |
| P1.02 | P1.02 | 向下导航 | 发送adhoc ping | 无 |
| P1.06 | P1.06 | 向左导航 | 刷机模式 (DFU) | 无 |
| P1.07 | P1.07 | 向右导航 | 无功能 | 无 |

## 烧录方法

### 方法1：UF2文件烧录（推荐）
1. 将nRF52 ProMicro DIY设备连接到电脑
2. 将 `firmware.uf2` 文件拖拽到设备存储
3. 设备将自动重启并加载新固件

### 方法2：HEX文件烧录
1. 使用nRF Connect或nRF52-DK工具
2. 选择 `firmware.hex` 文件
3. 按照工具提示进行烧录

### 方法3：ZIP文件烧录
1. 解压 `firmware.zip` 文件
2. 根据设备类型选择相应的固件文件
3. 按照对应方法进行烧录

## 文件说明

### 固件文件
- **`firmware.uf2`** - USB烧录文件，支持拖拽操作
- **`firmware.hex`** - 传统烧录工具使用的HEX文件
- **`firmware.zip`** - 包含所有编译产物的压缩包

### 信息文件
- **`firmware_info.txt`** - 详细的固件信息
- **`README.md`** - 本使用说明文档

## 使用说明

### 基本操作
- **短按按钮**：执行导航功能
- **长按按钮**：执行系统功能（需要按住3秒）
- **DFU模式**：长按P1.06按钮3秒进入刷机模式

### 功能说明
- **导航功能**：用于菜单导航和选择
- **系统功能**：关机、GPS切换、发送ping、进入DFU模式
- **深度睡眠**：所有按钮都支持从深度睡眠中唤醒设备

## 故障排除

### 常见问题

#### 1. 按钮无响应
- 检查按钮连接是否正确
- 确认固件已正确烧录
- 检查设备是否进入深度睡眠

#### 2. 烧录失败
- 检查USB连接
- 确认设备驱动已安装
- 尝试使用不同的烧录方法

#### 3. 功能异常
- 重新烧录固件
- 检查设备配置
- 查看系统日志
